## 2. Criterios de Evaluación Detallados

### Criterio 7.c1: Actualización Conceptual y Tecnológica
> **Definición**: *Actualiza conceptos y conocimientos necesarios para su desarrollo profesional y en especial para su proyecto en soluciones de ingeniería de software.*

| Nivel de Desempeño | Rango de Puntos | Indicadores de Cumplimiento |
| :--- | :---: | :--- |
| **Sobresaliente** | `[10 - 8>` | 1. Demuestra capacidad para asimilar y aplicar nuevas tecnologías, herramientas, nuevos conocimientos metodológicos y de procesos explicando fortalezas y debilidades en el ámbito de aplicación.<br>2. Demuestra capacidad para asimilar y aplicar conocimientos de más de un dominio de aplicación.<br>3. Demuestra dominio de técnicas o métodos para la investigación. |
| **Esperado** | `[8 - 7]` | 1. Demuestra capacidad para asimilar y aplicar nuevas tecnologías, herramientas, nuevos conocimientos metodológicos y de procesos.<br>2. Demuestra capacidad para asimilar y aplicar conocimientos de un dominio de aplicación.<br>3. Aplica técnicas o métodos para la investigación. |
| **Necesita Mejora** | `<7 - 0]` | 1. Demuestra parcialmente capacidad para asimilar y aplicar nuevas tecnologías, herramientas, nuevos conocimientos metodológicos y de procesos.<br>2. Demuestra parcialmente capacidad para asimilar y aplicar conocimientos de un dominio de aplicación.<br>3. Aplica parcialmente técnicas o métodos para la investigación. |

### Criterio 7.c2: Aprendizaje Permanente y Crecimiento Profesional
> **Definición**: *Reconoce la necesidad del aprendizaje permanente para el desempeño profesional y el desarrollo de proyectos en soluciones de tecnologías de ingeniería de software.*

| Nivel de Desempeño | Rango de Puntos | Indicadores de Cumplimiento |
| :--- | :---: | :--- |
| **Sobresaliente** | `[10 - 8>` | 1. Identifica y documenta áreas de crecimiento profesional donde le interesaría desarrollarse luego de graduarse.<br>2. Define rigurosamente un plan de crecimiento profesional alineado con las áreas de interés dentro de la profesión. |
| **Esperado** | `[8 - 6]` | 1. Identifica áreas de crecimiento profesional donde le interesaría desarrollarse luego de graduarse.<br>2. Define un plan de crecimiento profesional alineado con las áreas de interés dentro de la profesión. |
| **Necesita Mejora** | `<6 - 0]` | 1. Aunque reconoce la necesidad de mantenerse actualizado no demuestra capacidad para identificar áreas de crecimiento profesional donde podría desarrollarse luego de graduarse.<br>2. Demuestra dificultad para preparar un plan de crecimiento profesional alineado con las áreas de interés dentro de la profesión. |

## 3. Matriz de Evidencia Individual y Evaluación por Alumno

Cada integrante del equipo debe presentar en su *Individual Member Performance Report* (y en la sección Student Outcome del Informe Principal):

1. **Evidencias para 7.c1**:
   - Registro de nuevas tecnologías y frameworks asimilados (Android Kotlin, Jetpack Compose, Room, Retrofit, Ktor, etc.).
   - Análisis comparativo de fortalezas y debilidades de las tecnologías adoptadas.
   - Demostración de dominio de al menos un dominio de aplicación (p. ej. Marketplace B2B, Logística, Catálogo quesero).
   - Documentación del método de investigación y Spikes técnicos ejecutados.

2. **Evidencias para 7.c2**:
   - Plan de carrera individual post-graduación detallando áreas de interés (Arquitectura Cloud, Mobile Engineering, DevSecOps).
   - Plan de aprendizaje continuo: cursos, certificaciones, lectura técnica continua (bibliografía de referencia como Lean UX, Scrum SBOK, libros canónicos).
