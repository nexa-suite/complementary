# Nexa canonical guardrails

Use for any Nexa construction, documentation or implementation slice. Read the
current local `nexa-suite/blueprint/01-shared/product/current-decisions.md` and
the directly relevant canonical source before changing semantics.

- Authority is accepted Owner decisions, current Blueprint, verified modern
  implementation, current Design evidence, academic constraints, then history.
- Keep AS-IS, TARGET, FUTURE/OPEN, implementation evidence and Product
  Acceptance distinct.
- Never create a Bounded Context, database, provider, endpoint or client-owned
  domain authority without an accepted source.
- Blueprint is the only canonical C4/DDD/SQL model. Reports and generated
  artifacts explain or render it; they do not become another model.
