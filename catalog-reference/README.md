# Catalog assets

Assets reales de referencia para el catálogo B2B de Nexa.

- `assets/products/`: imágenes de productos, con nombres normalizados sin el espacio inicial heredado del mock.
- `assets/brands/`: logotipos de marcas presentes en el catálogo.
- Datos y schemas del catálogo: `../schemas/`, `../imports/` y `../migrations/`.

Estos archivos sirven para diseño, seed, pruebas visuales y validación de importación. El repositorio frontend sigue siendo la fuente de ejecución; esta carpeta es la fuente de referencia del producto.
