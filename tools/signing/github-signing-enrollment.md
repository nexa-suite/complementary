# GitHub SSH signing-key enrollment

For each contributor:

1. Sign in to their own GitHub account.
2. Open Settings -> SSH and GPG keys -> New SSH key.
3. Choose `Key type = Signing Key`.
4. Set title `Nexa Shared MacBook Signing`.
5. Paste only corresponding `.pub` key.
6. Save it.
7. Ensure commit email is associated with and verified by that GitHub account.
